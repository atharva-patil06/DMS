      Let A be a finite set and R ⊆ A × A a relation.

      Reflexive
      ∀a ∈ A, (a,a) ∈ R
      Symmetric
      (a,b) ∈ R ⇒ (b,a) ∈ R
      Antisymmetric
      (a,b) ∈ R ∧ (b,a) ∈ R ⇒ a = b
      Transitive
      (a,b) ∈ R ∧ (b,c) ∈ R ⇒ (a,c) ∈ R
      Partial order (POSET)
      Reflexive, antisymmetric and transitive. Written (A, ≤).
      Equivalence relation
      Reflexive, symmetric and transitive. It splits A into equivalence classes [a] = {b : a R b}.
      Comparable
      a and b are comparable iff a ≤ b or b ≤ a.
      Covering relation
      b covers a iff a < b and there is no c with a < c < b.
      Hasse diagram
      The graph of the covering relation: smaller elements lower, no loops, no edges implied by transitivity, no arrowheads (direction is upward).
      Minimal / maximal
      No element strictly below / above it. There can be several.
      Least / greatest
      Below / above every element. Unique if it exists.
      Upper / lower bound of S
      u with s ≤ u for all s ∈ S / l with l ≤ s for all s ∈ S.
      lub (join, ∨) / glb (meet, ∧)
      The least upper bound / greatest lower bound, if it exists.
      Lattice
      A poset in which every pair {a,b} has both a lub and a glb.
      Chain / antichain
      Every two elements comparable / no two distinct elements comparable.
      Height / width
      Size of a longest chain / of a largest antichain.
      Warshall's algorithm
      For k = 1..n: W[i][j] = W[i][j] OR (W[i][k] AND W[k][j]). The result is the transitive closure R+.
